# 05 — Checklist SEO + Inbound

## SEO on-page
- [ ] Keyword principal definida
- [ ] Title / H1 alineados al intent
- [ ] Meta description clara + CTA

## Inbound

- [ ] CTA único por pieza
- [ ] Nutrición (email/WhatsApp) definida
- [ ] Página de destino consistente con el anuncio
